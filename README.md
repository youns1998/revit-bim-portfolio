# Revit · BIM Portfolio

Revit 모델링과 도면화 과정을 기록하는 포트폴리오 저장소입니다.
모델의 구성, 설계 판단, 도면과 수량 산출 결과를 함께 정리합니다.

**현재 상태: 작업 준비.** 아직 완성된 Revit 모델이나 결과 도면은 등록하지 않았습니다.

## 첫 작업 계획

기존 2층 단독주택 CAD 도면을 바탕으로 Revit 모델링을 진행하는 것을 첫 작업 후보로 정했습니다.
아래 항목은 앞으로 진행할 계획이며 완료 실적을 의미하지 않습니다.

- [ ] 작업 기간, 참고 도면과 직접 수행할 범위 정리
- [ ] 레벨과 그리드 설정
- [ ] 벽, 바닥, 지붕과 개구부 모델링
- [ ] 계단과 층별 공간 연결 검토
- [ ] 평면·입면·단면 뷰와 시트 구성
- [ ] 문·창호 또는 실 일람표 작성
- [ ] 대표 이미지와 PDF 출력, 모델·도면 간 일치 여부 확인
- [ ] 주요 판단과 수정 과정을 작업 기록에 정리

## 폴더 구성

| 경로 | 내용 |
| --- | --- |
| `models/` | 직접 작성한 Revit 모델 |
| `exports/images/` | 모델, 뷰, 시트의 대표 이미지 |
| `exports/pdf/` | Revit에서 출력한 도면집 |
| [docs/project-notes.md](docs/project-notes.md) | 작업 조건, 수행 범위와 설계·모델링 판단 기록 |

모델 파일명은 `house-model.rvt`, 결과물은 `house-floor-plan.png`, `house-sheets.pdf`처럼 내용을 구분할 수 있게 작성합니다.
자동 생성된 번호 백업과 임시 파일은 Git에서 제외합니다.

## 작업 환경

로컬 PC에 Revit 2026이 설치되어 있습니다. 실제 모델을 등록할 때 사용한 Revit 버전과 필요한 패밀리·링크 파일을 작업 기록에 명시합니다.

외부 도면이나 패밀리를 참고한 경우 출처와 활용 범위를 기록합니다. 프로젝트 결과물은 확인이 끝난 뒤 포트폴리오에 연결합니다.
